## Investment Thesis

All startups were evaluated using the same investment framework:

* Self-serve onboarding
* Less than 15-minute setup
* Autonomous value creation
* Minimal operational friction
* Defensibility against competitors

This consistent framework allows startups from different categories to be compared using the same criteria.
